PRESENÇA IFBA — CORREÇÃO DE FOTO E GRAVAÇÃO DE RESPOSTAS

1. Faça backup do repositório atual.
2. Extraia este ZIP.
3. Substitua TODOS os arquivos na raiz do GitHub Pages pelos arquivos deste pacote.
4. No Supabase > SQL Editor, execute TODO o arquivo supabase.sql.
5. Aguarde o GitHub Pages publicar e recarregue com Ctrl + Shift + R.

TESTE: crie um evento de teste com uma foto, gere o link, abra em outro celular e envie uma resposta. A tela deve dizer:
“Formulário respondido com sucesso! Sua resposta foi registrada.”

Depois confira a linha em Supabase > Table Editor > public.form_responses e a aba Respostas do administrador.

O SQL cria o bucket event-banners e as permissões de Storage e de envio público. Não apaga eventos nem respostas.
