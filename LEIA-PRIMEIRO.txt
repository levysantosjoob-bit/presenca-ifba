PRESENÇA IFBA — VERSÃO COM FORMULÁRIO COMPARTILHADO

O QUE FOI CORRIGIDO
- O evento é salvo no Supabase, não apenas no navegador de quem administra.
- O link usa o UUID real do evento salvo no banco.
- O celular que abre o link consulta o evento no Supabase.
- As respostas são gravadas em form_responses e aparecem no painel.
- O acesso administrativo usa Supabase Auth e a verificação public.is_admin().

PARA PUBLICAR
1. Faça backup dos arquivos atuais do GitHub.
2. Extraia o ZIP.
3. Substitua index.html, style.css e app.js na raiz do repositório GitHub.
4. Envie também README.md e supabase.sql.
5. Faça commit na branch main e aguarde o GitHub Pages publicar.
6. No SQL Editor do Supabase, execute o arquivo supabase.sql.
7. Entre no painel, crie um NOVO evento e gere o link. Eventos antigos que só existiam no armazenamento local precisam ser cadastrados novamente.

TESTE
Abra o link em outro celular ou janela anônima, envie uma resposta de teste e confira em Respostas no painel.

ATENÇÃO
A validação de GPS ainda ocorre no navegador e não é segura no servidor. Não utilize o sistema com dados reais antes de testar login, abertura do link e gravação das respostas.
