PRESENÇA IFBA — LEIA PRIMEIRO

IMPORTANTE: EXISTEM DUAS PÁGINAS SEPARADAS

1. index.html — painel administrativo. Só a equipe autorizada entra com e-mail e senha.
2. presenca.html?id=UUID — formulário público independente. O estudante abre o link no celular e responde sem login, e-mail, senha ou código.

COMO PUBLICAR
1. Faça backup do repositório GitHub.
2. Extraia o ZIP.
3. Envie todos os arquivos para a raiz do repositório, substituindo os arquivos antigos.
4. Faça commit e aguarde o GitHub Pages publicar.
5. Abra o SQL Editor do Supabase e execute supabase.sql.

COMO USAR
1. Entre no painel administrativo.
2. Crie e salve um evento.
3. Clique em “Gerar formulário + QR Code”.
4. Compartilhe o link gerado. Ele abre diretamente a página pública, sem passar pelo painel.
5. O estudante responde. Se o GPS estiver ativado, precisa autorizar a localização e estar em uma localidade permitida.
6. No painel, abra “Respostas” no evento para acompanhar os registros. Com o Supabase Realtime configurado, novas respostas aparecem automaticamente sem atualizar a página.

TESTE ANTES DE USAR
Abra o link em outro celular sem estar logado, envie uma resposta e confira no painel. Deixe a tela de respostas aberta e envie uma segunda resposta para testar a atualização em tempo real.

ATENÇÃO
A validação GPS ainda é feita no navegador e não é inviolável. A integração depende das políticas RLS existentes no Supabase. Não utilize com dados oficiais antes de concluir os testes.
