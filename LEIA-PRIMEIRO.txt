PRESENÇA IFBA — PRIMEIRA ETAPA: LOGIN ADMINISTRATIVO COM SUPABASE

O que foi alterado nesta versão:
- O login demonstrativo que aceitava qualquer e-mail/senha foi removido.
- O sistema agora usa Supabase Auth (e-mail e senha).
- Depois do login, consulta a função public.is_admin() para confirmar que a conta está na lista de administradores.
- A sessão é mantida pelo Supabase e o botão Sair encerra a sessão.
- A conta já cadastrada no Supabase Auth e em public.admin_users deve ser usada; não é necessário criar outra conta.

ANTES DE PUBLICAR:
1. Abra config.js.
2. Substitua COLE_AQUI_SUA_CHAVE_SB_PUBLISHABLE pela chave pública publishable do projeto Supabase kvcqgceqgmagqlcazrxa (formato sb_publishable_...).
3. Não coloque chave secret nem service_role nesse arquivo.
4. Confirme no Supabase Authentication → URL Configuration que o endereço https://levysantosjoob-bit.github.io está permitido.
5. Publique os arquivos index.html, app.js, style.css, config.js, README.md e LEIA-PRIMEIRO.txt na raiz do GitHub Pages.

IMPORTANTE — ESCOPO DESTA ETAPA:
Esta entrega corrige a autenticação administrativa. O restante do aplicativo ainda contém partes demonstrativas que usam localStorage. Eventos, formulários públicos, respostas, banners e validação GPS ainda NÃO foram migrados integralmente para o Supabase. Não use esta versão como sistema de presença em produção até concluir e testar essas integrações.

A função public.is_admin() já existente precisa estar acessível por RPC para usuários autenticados e continuar verificando auth.uid() contra public.admin_users. Não altere nem exclua o usuário administrador existente.
